# 命运绿茵 - 球员生涯模拟

AI 驱动的足球球员生涯模拟游戏。创建你的球员，经历完整的职业生涯——训练、比赛、转会、伤病、合同谈判，在随机事件中做出选择，书写属于你的绿茵传奇。

## ✨ 核心特性

### 角色系统
- **28 项属性**：15 项硬实力（射门、传球、速度等）+ 13 项软实力（意志力、抗压、声望等）
- **14 种正面特点**（快马、空霸、传球大师等）+ **8 种负面特点**（玻璃人、独狼等），最多选 4 个，点数仅在同类间流转
- **年龄影响**：年轻球员初始能力打折，随赛季成长；30 岁后开始下滑
- **5 级球队等级**：豪门 / 劲旅 / 中游 / 下游 / 弱旅，决定初始属性范围

### 赛季系统
- 每赛季 **6 回合**：夏窗 → 上半前期 → 上半后期 → 冬窗 → 下半前期 → 下半后期
- 每回合 **4 个随机事件**，AI 生成——比赛、训练、转会、媒体、伤病等
- **3 选项**各含正面+负面隐含效果，选择影响属性走向
- **软实力影响事件质量**：属性高 → 倾向好事，属性低 → 倾向坏事
- **类别限制**：同类别每回合最多 2 次，比赛表现每回合必出 1 次
- **自由对话**：找教练/队友/经纪人/记者聊天，影响事件类型和属性

### 合同 & 转会
- **完整合同系统**：周薪、年限、解约金、工资等级（童工→顶薪）
- **转会兴趣计算**：基于表现、声望、球队等级、合同年限综合打分
- **AI 谈判**：收到报价后可与俱乐部代表多轮对话谈判（最长 4 轮）
- 转会/续约后 2 赛季冷却期内不再报价
- 签约大合同 → 声望加成；降价续约 → 口碑奖励

### 更衣室地位
- **5 级地位**：边缘人物 → 普通成员 → 重要角色 → 核心领袖 → 传奇
- 由实力匹配度、社交属性、工资、资历、表现、年龄 6 大因子综合计算
- 地位影响出场时间（传奇×1.3，边缘×0.65）
- 冬窗和夏窗结算变动

### 成长 & 溢出
- **赛季末成长**：根据本季涉及的事件类别，相关属性获得成长点数
- **溢出转移**：满 99 的属性点数自动跳转到其他属性，结算面板显示 `↪ 射门+1→速度`
- **年龄差异化**：年轻球员净涨多、扣回少；年长持平；老化期温和下滑

### 生涯记录
- 每赛季结束后自动记录：出场、进球、助攻、球队排名
- **赛季奖项评选**（高门槛）：金球奖、联赛 MVP、最佳阵容、金童奖等
- **58 项成就**：里程碑、荣誉、事件、巅峰、更衣室、合同、转会、特点 8 大类
- 生涯面板可回顾每赛季数据 + 荣誉 + 奖项

### 存档 & 发布
- **自动存档**：每步操作后自动保存 JSON
- **手动命名存档**：随时保存到自定义槽位
- 一键打包 **EXE**（PyInstaller），Windows 双击即玩
- 支持移动端适配

## 🛠 技术栈

### 后端
| 技术 | 用途 |
|------|------|
| **Python 3.8+** | 主要开发语言 |
| **FastAPI** | 异步 Web 框架，提供 REST API + SSE 流式端点 |
| **Uvicorn** | ASGI 服务器，支持高并发异步请求 |
| **Pydantic v2** | 数据模型校验、序列化、类型安全 |
| **HTTPx** | 异步 HTTP 客户端，复用连接池调用 AI API |

### AI 集成
| 技术 | 用途 |
|------|------|
| **DeepSeek API** | 大语言模型，OpenAI 兼容格式（可替换为任意兼容服务） |
| **SSE 流式响应** | Server-Sent Events 实现 AI 叙事逐字输出，提升体验 |
| **Prompt Engineering** | 约 10 个不同场景的结构化提示词（事件生成/结算/谈判/新闻等） |

### 前端
| 技术 | 用途 |
|------|------|
| **原生 HTML5** | 语义化结构，单页面应用 |
| **原生 CSS3** | CSS 变量体系、Flexbox/Grid 布局、动画、响应式 |
| **原生 JavaScript** | Fetch API + ReadableStream 消费 SSE、模板字符串渲染、0 依赖 |
| **模块化** | index.html + style.css + app.js 三文件分离 |

### 数据 & 工程
| 技术 | 用途 |
|------|------|
| **JSON 文件存储** | 存档系统，原子写入（.tmp → os.replace 防断电） |
| **Counter 算法** | 事件类别去重、每回合 2 次上限控制 |
| **PyInstaller** | 打包为独立 EXE（含 Python 运行时 + 前端 + OpenSSL DLL） |
| **环境变量** | API Key 等敏感配置通过 os.getenv 读取，不进仓库 |

## 🚀 快速开始

### 方式一：Python 运行

```bash
# 1. 安装依赖
pip install fastapi uvicorn httpx pydantic

# 2. 设置 API Key（可选，已内置默认值）
set DEEPSEEK_API_KEY=your-key-here

# 3. 启动
cd backend
python main.py

# 4. 浏览器打开
http://127.0.0.1:8000
```

### 方式二：EXE 运行

双击 `dist/命运绿茵.exe`，自动打开浏览器。

## 📁 项目结构

```
├── backend/
│   ├── main.py          # FastAPI 服务 + 所有 API 端点
│   ├── ai_engine.py     # AI 对话引擎（事件生成/结算/合同谈判/新闻扩写）
│   ├── game_state.py    # 游戏状态管理（球员/赛季/存档/成长/转会/地位）
│   ├── config.py        # 常量定义（属性/特点/球队等级/回合）
│   ├── models.py        # Pydantic 数据模型
│   └── achievements.py  # 成就系统（58 项 + 检测逻辑）
├── frontend/
│   └── index.html       # 单文件前端（1900+ 行）
├── dist/
│   └── 命运绿茵.exe     # 打包后的可执行文件
└── README.md
```

## ⚙️ 配置

```bash
# 必须设置 API Key（从 DeepSeek 控制台获取）
export DEEPSEEK_API_KEY=sk-your-key-here

# 可选：自定义 API 地址和模型
export DEEPSEEK_BASE_URL=https://api.deepseek.com
export DEEPSEEK_MODEL=deepseek-chat
```
